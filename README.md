# Real-Time Chat Application

A real-time chat application built using Flask and Flask-SocketIO.

## Features

* Real-time messaging
* Voice messages
* Image sharing
* File sharing
* Emoji support
* Typing indicator
* Online user tracking
* Message timestamps
* Notification sounds

## Tech Stack

* Python
* Flask
* Flask-SocketIO
* HTML
* CSS
* JavaScript

## Installation

```bash
pip install flask flask-socketio
python app.py
```
